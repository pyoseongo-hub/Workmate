# 손으로 눌러 보는 검사

진짜 브라우저를 띄워 앱을 눌러 보는 검사입니다.
**타입 검사(`pnpm check`)로는 안 잡히는 것들이 여기서 잡힙니다** —
버튼을 눌렀는데 아무 일도 안 일어나는 것 같은 사고요.

## 먼저 서버를 띄웁니다

```bash
pnpm build
PORT=3000 node dist/server.js          # 창 하나를 차지합니다. 다른 창에서 검사를 돌리세요
curl -s localhost:3000/api/health      # {"ok":true,...} 가 나와야 합니다
```

크로뮴은 한 번만 깔아 둡니다: `pnpm exec playwright install chromium`
(다른 크로뮴을 쓰려면 `CHROME_PATH=경로` 로 줍니다)

## 검사 돌리기

```bash
node tests/번호.mjs        # 번호가 화면·응답에 없나, 틀리면 막히나, 이름만 고쳐도 남나
node tests/삭제.mjs        # 지우기 네 곳 (근무·교대·근무일지·직원)
node tests/알림.mjs        # 확인 버튼 · 알림 · 종 배지
node tests/동시등록.mjs    # 브라우저 둘로 동시에 넣어도 안 사라지나
node tests/사용법.mjs      # 사용법 화면
node tests/판번호.mjs      # 판 번호 충돌 (브라우저 없이 API 만)
```

숫자를 재는 것들:

```bash
node tests/부하.mjs        # 탭 하나가 1분에 서버를 몇 번 부르나
node tests/자료크기.mjs    # 1년 쓴 매장이 얼마나 내려오나
node tests/화면꺼짐.mjs    # 다른 탭으로 가면 정말 멈추나
```

화면 사진은 `tests/결과/` 에 쌓입니다.

## 지금 기준값 (2026-09-03)

| 검사 | 나와야 하는 값 |
|---|---|
| `부하.mjs` | 1분에 **8회** 안팎 (43회면 시계가 다시 쪼개진 것) |
| `자료크기.mjs` | 8초마다 **68 B** (471 KB 면 통째로 내려받는 것) |
| `화면꺼짐.mjs` | 안 볼 때 **0회**, 돌아오면 즉시 1회 |
| `동시등록.mjs` | 근무 **2건** (1건이면 한 명 것이 사라진 것) |

## 왜 이걸 붙였나

사장님이 화면 캡처로 **"삭제 안되는데"** 를 짚어 주셨습니다.
그때까지 타입 검사만 돌리고 손으로 눌러 보지 않았습니다.

원인은 브라우저 `confirm()` 이었습니다 — 안전 상자(iframe sandbox) 안에서는
창을 안 띄우면서 **조용히 "취소"를 돌려줍니다.** 오류도 안 납니다.
그래서 근무·교대·근무일지·직원 **네 곳이 전부** 먹통이었는데
코드만 봐서는 멀쩡해 보였습니다.

**사람이 짚어 주기 전에 기계가 먼저 잡게 하려고 만들었습니다.**
