# 인터넷에 올리기

> ✅ **2026-09-03 에 끝났습니다.** 주소: **https://workmate-cww0.onrender.com**
> Neon 프로젝트 `workmate` · Render 웹 서비스 `workmate` (Blueprint). 아래는 그때 밟은 절차입니다.
> 다시 올릴 일은 없습니다 — 브랜치에 push 하면 Render 가 저절로 다시 올립니다.

앱을 인터넷에 올려서, 사장님과 알바생이 각자 폰에서 쓰게 만드는 방법입니다.
**두 곳에 가입**하면 됩니다. 둘 다 **무료**이고, 구글 계정으로 클릭 몇 번이면 끝납니다.

| 무엇 | 어디 | 하는 일 |
|---|---|---|
| 자료 창고 | **Neon** | 근무표·직원·교대를 담아 둡니다 |
| 앱 올릴 곳 | **Render** | 앱 화면을 보여주고 창고와 이야기합니다 |

---

## 1단계 — 자료 창고 만들기 (Neon)

1. https://neon.tech 에 들어가 **Sign up** → 구글 계정으로 가입
2. **Create project** 를 누릅니다
   - Project name: `workmate` (아무거나 괜찮습니다)
   - Region: **Singapore** (한국에서 가장 가깝습니다)
3. 만들어지면 **Connection string** 이 보입니다. 이렇게 생긴 긴 주소입니다:

   ```
   postgresql://이름:비밀번호@어디.neon.tech/무엇?sslmode=require
   ```

4. **이 주소를 복사해 둡니다.** 다음 단계에서 씁니다.

> ⚠️ 이 주소에는 비밀번호가 들어 있습니다. 카톡이나 메모장에 남기지 말고,
> 바로 다음 단계에 붙여넣으세요.

---

## 2단계 — 앱 올리기 (Render)

1. https://render.com 에 들어가 **Get Started** → **GitHub 계정으로** 가입
2. **New +** → **Web Service**
3. 저장소 목록에서 **Workmate** 를 고릅니다
   - 안 보이면 **Configure account** 를 눌러 Render 가 저장소를 볼 수 있게 허용합니다
4. Branch 를 작업 브랜치로 고릅니다 (예: `claude/workmate-project-rebuild-0g0b5d`)
5. 나머지는 **건드리지 않아도 됩니다.** `render.yaml` 에 다 적혀 있습니다.
6. 아래로 내려가 **Environment Variables** 에서 **Add Environment Variable**:
   - Key: `DATABASE_URL`
   - Value: **1단계에서 복사한 주소**
7. **Create Web Service** 를 누릅니다

5~10분 기다리면 주소가 나옵니다:

```
https://workmate-xxxx.onrender.com
```

---

## 3단계 — 매장 열기

1. 위 주소를 폰에서 엽니다
2. **매장 새로 열기** → 매장 이름을 넣습니다
3. **사장님 이름과 번호(4자리)** 를 정합니다
4. **직원 관리**에서 직원을 추가하고 각자 번호를 정합니다
5. **카카오톡으로 초대하기** 를 눌러 알바생에게 링크를 보냅니다

알바생은 링크를 열고 **자기 이름 + 번호**만 넣으면 됩니다. 가입할 필요가 없습니다.

## 알아 두면 좋은 것

### 무료 플랜은 15분 쉬면 잠듭니다

Render 무료 플랜은 아무도 안 쓰면 서버가 잠듭니다.
그 뒤 처음 여는 사람은 **30초쯤** 기다립니다. 그 다음부터는 빠릅니다.

늘 빠르게 하려면 Render 유료 플랜(월 7달러쯤)으로 올리면 됩니다.

### 자료는 창고에 남습니다

서버가 잠들거나 다시 켜져도 근무표는 그대로입니다. 창고(Neon)에 있기 때문입니다.

### 매장 코드를 잃어버리면

직원 관리 화면에 여섯 글자가 크게 적혀 있습니다. 그걸 알려 주면 됩니다.
사장님 폰에서 앱을 지웠다면, 창고에는 남아 있으니 코드만 알면 다시 들어갈 수 있습니다.

- 번호를 다섯 번 틀리면 5분 동안 막힙니다
- **작은 매장에서 서로 아는 사람끼리** 쓰는 것을 전제로 한 수준입니다

더 단단하게 하려면 들어온 사람에게 표를 주고, 저장할 때마다 표를 확인해야 합니다.
지금은 그 전 단계입니다.
