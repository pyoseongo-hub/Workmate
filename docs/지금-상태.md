## ⌨️ 시작 명령어
💻 **2026-09-03 부터 사장님 윈도우 PC 에서 작업한다.** 리눅스 샌드박스 이야기(`/home/user`, `setsid`, `/opt/pw-browsers`)는 이제 안 맞는다.
명령은 **Git Bash** 에서 돌린다 (PowerShell 도 되지만 `PORT=3000 …` 꼴이 안 먹는다).


## 🩹 겪은 사고와 교훈

### ① 삭제가 안 됐다 — `confirm()` 이 조용히 거짓말한다

앱을 안전 상자(iframe sandbox) 안에서 열면 브라우저가 `confirm()` 창을 **안 띄운다.**
그런데 오류를 내지 않고 **조용히 `false`(취소)를 돌려준다.**
→ 앱은 "사용자가 취소했구나" 하고 넘어간다. 화면엔 아무 일도 안 일어나고 오류도 없다.
근무·교대·근무일지·직원 **네 곳이 전부** 이래서 먹통이었다.
→ `useConfirm` 으로 앱이 직접 창을 그린다.

### ② 동시에 고치면 한 명 것이 사라졌다

목록을 통째로 덮어쓰는 구조라, 사장님과 알바생이 **8초 안에** 각자 근무를 넣으면
나중 사람이 앞사람 것을 지웠다. **오류도 안 떴다.** 사람 수와 무관한 버그였다.
→ 판 번호(version). 맞을 때만 저장하고, 어긋나면 서버가 최신 목록을 돌려준다.
   앱이 거기에 자기 것을 **다시 얹어서** 보낸다(최대 4번).

### ③ 켜 두기만 해도 서버를 1분에 43번 불렀다

자료 종류마다 각자 8초 시계를 갖고 있었고, 부를 때마다 매장 자료를 **통째로** 내려받았다.
1년 쓴 매장은 한 번에 471KB. 바뀐 게 없어도, 화면을 안 보고 있어도 그랬다.

| | 전 | 후 |
|---|---|---|
| 1분당 호출 | 43회 | **8회** |
| 8초마다 내려오는 양 | 471 KB | **68 B** |
| 하루 8시간 | 9.3 GB | **0.7 MB** |
| Render 무료로 버틸 사람 | 0명 | **6,713명** |

→ ⓐ시계 하나로 합침 ⓑ판 번호만 묻고 바뀐 것만 받음 ⓒ화면 안 보면 멈춤

### ④ 고치다가 깨뜨린 것 — 검사가 잡아 줬다

②③ 을 고친 뒤 **알림을 읽어도 종 배지가 안 사라졌다.**
종과 알림 목록이 같은 자료를 각자 보는데, "판 번호가 그대로면 안 받아 온다"로
바꾸는 바람에 서로를 모르게 됐다.
→ 저장한 쪽이 같은 자료를 보는 화면들에 직접 알린다(`notifyListeners`).

**교훈: 성능을 고치면 "저절로 맞춰지던 것"이 같이 끊긴다. 검사를 꼭 다시 돌린다.**

### ⑤ 그 밖에 걸렸던 것

- `Card` 에 이미 `py-6` 이 있다. `p-5` 를 더하면 여백이 두 배 → **`py-0` 을 붙인다**
- 달력 `min-w-[680px]` 이 폰에서 수·목·금·토를 잘랐다 → `min-w-full sm:min-w-[680px]`
- 사람 색은 **목록 순서가 아니라 `member.id`** 로 고른다. 앞사람을 지우면 색이 우르르 바뀐다
- 첫 화면이 12.7초 걸렸다 → 개발용 스크립트 358KB 를 뺐더니 **0.2초**
